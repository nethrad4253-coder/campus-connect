# Campus Connect — Final Review (Fixed)

Student: Events, Clubs, Workshops, Community, Student Connect, Team Finder, Notifications.
Admin: Dashboard, Admin Control Center, Workshops, Notifications, Admin Profile.

Student-created Events and Clubs require Super Admin approval.
Admin-created Workshops are published immediately and notify students.

Keep your existing `.env` file with your MongoDB Atlas credentials.
Run `npm install` then `npm start` and open http://localhost:3001.
